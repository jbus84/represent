🔬 Methodology

🎯 Merton Jump Diffusion Model

Model: dS/S = μdt + σdW + (e^J - 1)dN

  • μ: Drift coefficient
  • σ: Diffusion volatility
  • J: Jump size (normally distributed)
  • N: Poisson jump process

Key Innovation: Models both continuous price movements and sudden jumps, providing superior tail prediction for extreme market events.

📊 Key Metrics

  • Balance Score: 1 - (max_deviation / expected_fraction) - measures distribution uniformity
  • Tail Score: Weighted error for classes 0 & 12 (extreme events) - lower is better
  • Extreme Concentration: Combined percentage in classes 0 + 12 (target: 15.4%)
